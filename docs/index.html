VendroidEnhanced 수식 빌드

기존 BetterMarkdown 수정본을 포함한 비공식 Vencord 모바일 웹 빌드입니다.

  1. 사용자 설정 → VendroidEnhanced Settings → Client mod: Vencord
  2. Other → Open developer settings → Vencord location에 아래 주소를 입력합니다.
  3. Android 앱 설정에서 강제 종료한 뒤 재실행합니다.
  4. Vencord → Plugins → BetterMarkdown을 켜고 Enable Math를 켭니다.

https://msh18993.github.io/vendroid-math/browser.js

PC·Tailscale은 필요하지 않지만 앱 완전 재시작 시 GitHub Pages, 수식 로딩 시 KaTeX CDN에 접속할 수 있어야 합니다.

기기 검증 대기: 호스트 테스트와 웹 빌드는 통과했으나 실제 Android 앱에서 활성화·수식 표시·복사·완전 재시작은 아직 확인하지 않았습니다. 기존 공식 Discord 앱을 유지하세요.

문제가 있으면 BetterMarkdown을 끄거나 VendroidEnhanced 복구 모드에서 기본 빌드로 복구하세요. 기본 빌드로 돌아가면 수식 플러그인은 빠집니다.
